sitemap-autogenerator

An Ember AddOn for ember-cli that automatically generates a sitemap.xml file and adds it to your project during build time.

GitHub Repository Get Started

Compatibility

Dependency Version
Ember.js v3.16+
Ember CLI v2.13+
Node.js v10+

Installation

npm install --save-dev sitemap-autogenerator

Usage

"postbuild": "node -e \"require('./node_modules/sitemap-autogenerator/blueprints/sitemap-autogenerator/index').triggerSitemapBuilder('<YOUR SITE ROOT URL>')\""

Do not include a trailing slash after your root URL or the generated sitemap may contain double slashes.

Features

Automatic Generation

Generate sitemap.xml automatically after every build.

Nested Routes

Supports nested Ember route structures.

Custom Priorities

Assign route specific priority values.

Ignore Routes

Exclude routes from sitemap generation.

External Paths

Include URLs outside the Ember router.

Build Integration

Works directly with Ember build lifecycle hooks.

Configuration Example

ENV['sitemap-autogenerator'] = {
  changeFrequency: 'weekly',
  defaultPriorityValue: '0.3',
  showLog: true,

  ignoreTheseRoutes: {
    'contact-us': true,
    'contact': true,
    'careers': true
  },

  customPriority: {
    'general': '0.7',
    'systemapplicationdeveloper': '0.9'
  },

  pathsOutsideEmberApp: [
    'blog',
    'some/other/path.html'
  ]
};

Generated Sitemap Example

<?xml version="1.0" encoding="UTF-8"?>
<urlset xmlns="http://www.sitemaps.org/schemas/sitemap/0.9">

  <url>
    <loc>https://www.example.com/</loc>
    <lastmod>2025-01-01</lastmod>
    <changefreq>daily</changefreq>
    <priority>0.9</priority>
  </url>

</urlset>

Current Limitations

  • Dynamic routes such as /artist/:artist_id are not supported.
  • Image sitemaps are not supported.
  • Video sitemaps are not supported.
  • Rich media sitemap extensions are not supported.
